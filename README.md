## 🧟 About the Project

This project is a Java implementation inspired by the popular tower-defense game  
**Plants vs. Zombies 2**.

The player must protect the lawn from increasingly dangerous waves of zombies by selecting and planting different types of plants. Each plant has unique abilities, costs, cooldowns, attacks, and special effects, while zombies have different movement patterns, armor types, and behaviors.

The game is built around a **tick-based simulation**, where plants, zombies, projectiles, resources, environmental effects, and waves are updated as time advances. Online accounts and I, Zombie matchmaking remain available in the project when its server is configured.

## 🪟 Offline Windows Release

The portable Windows x64 ZIP is an offline player edition. Its network menu and online services are disabled in the packaged launcher; the project source retains the network features. The ZIP includes its Java runtime and game assets, so no separate Java installation or internet connection is required.

1. Extract the ZIP completely to a folder.
2. Run `PvZ_MPH Edition.exe`.
3. Keep the `assets`, `app`, and `runtime` folders beside the executable.

Local accounts and game progress are stored under `%APPDATA%\phase-0-group-66`.
