راهنمای نسخهٔ آفلاین Windows - Plants vs. Zombies 2 - PvZ_MPH Edition

1) فایل ZIP را کامل در یک پوشه استخراج کنید؛ بازی را از داخل ZIP اجرا نکنید.
2) فایل PvZ_MPH Edition.exe را اجرا کنید.
3) پوشه‌های assets، app و runtime باید کنار فایل EXE باقی بمانند.
4) فایل README.md توضیحات پروژه و مشخصات دانشگاهی را دارد.

نصب Java یا اتصال اینترنت لازم نیست. اطلاعات حساب محلی، پیشرفت بازی و گزارش‌ها
در پوشهٔ %APPDATA%\phase-0-group-66 ذخیره می‌شوند.

اگر بازی متوقف شد، فایل logs\phase-0-group-66.log را در پوشهٔ بالا بررسی کنید.
